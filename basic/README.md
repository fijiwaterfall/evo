# EVO basic — простий світ реплікаторів

Запуск із `E:\evo`: `node basic/server.mjs`, потім http://127.0.0.1:8100.
Тести: `node --test basic/core.test.mjs basic/worker.test.mjs`.
Без браузера: `node basic/headless.mjs --size=128 --ticks=2000 --seed=1`.
Залежності: Node.js та сучасний браузер; сторонні пакети не потрібні.

## Модель

П’ять генів: рух, чутливість до УМП, поглинання, зв’язування та тривалість життя. Фізичні пружні зв’язки утворюються за взаємної здатності при контакті й розриваються при розтягненні або смерті. Передачу УМП й ген провідності повністю прибрано. Нащадки формують зв’язки самі. Початкова здатність слабка випадкова; доступний контроль із нульовою здатністю.

Тривалість життя записана п’ятим геном як додатне ціле число кроків, початково 1000 у всіх засновників. Це початкове значення, не загальна стеля: нащадок успадковує ген із тією самою імовірністю мутації, що й інші гени. Для гена часу існуючий крок ±0.1 виражений у базових одиницях 1000 кроків: зміна до ±100 кроків з округленням; нижня межа 1. Довжина життя може як зменшитися, так і збільшитися; штучної біологічної верхньої межі немає (лише межа безпечного цілого Number.MAX_SAFE_INTEGER).

На кроці, коли age досягає гена життя, істота помирає до перевірки поділу. Невитрачена енергія повертається в її клітинку, зв’язки видаляються. Вік батька не обнуляється, нащадок починає з нуля. Якщо одночасно досягнуті межа віку й виснаження, причина в лічильнику — старість; смерть рахується один раз. Обидві причини смерті показані окремо.

Немає fitness-функції, автозаселення, обмеження чисельності чи винагороди за складність. Покоління — максимальна глибина родоводу серед живих, крок — час світу. Це різні показники. Поділ, механіка руху та мутації перших чотирьох генів залишаються попередніми.

## Ресурс

УМП трактуємо як доступний поживний субстрат, запас якого умовно вимірюється в енергетичних одиницях. Це не вся енергія біосистеми й не фізично відкалібрована біохімія.

Погоджено: кожна клітинка рівномірно обмінюється ресурсом із зовнішнім середовищем. За крок `ΔR = renewal × (concentration − R)`, початково concentration = 2, renewal = 0.002 (0.2%). Позитивний обмін — приплив, негативний — відтік. Центрального джерела більше немає. Локальне поглинання створює неоднорідність, дифузія її згладжує. За відсутності істот рівномірне поле наближається до зовнішньої концентрації замість необмеженого накопичення. renewal = 0 вимикає обмін. Початкове поле дорівнює обраній concentration.

Принципи локального споживання та чисельної дифузії спираються на [просторову модель мікробних спільнот](https://www.nature.com/articles/s41467-018-03187-y). Рівномірний обмін у кожній клітинці — наше погоджене спрощення середовища з розподіленим підживленням, а не відтворення геометрії пор чи всіх механізмів цієї статті. Стаття не обґрунтовує наші числові параметри.

Баланс: початкова енергія + приплив = поле + живі істоти + розсіювання + відтік. Витрати існування, руху, сенсорики, поглинання та поділу розсіюються. Після смерті в поле повертається лише невитрачений залишок. Пружина — геометрична модель без окремої механічної енергії.

## Обчислення та масштаби

- `core.mjs`: детерміновані правила, масиви Float64, попередньо обчислені сусіди сітки, просторовий індекс контактів.
- `runner.mjs`: кроки світу, історія вимірювань кожні 10 кроків; незалежні від знімків.
- `worker.mjs`: окремий Web Worker, ліміт часу на пакет розрахунку. 10/40/160 кроків/с або максимум; pause/step/reset обробляються між пакетами.
- `app.mjs`: отримує копії стану, малює через requestAnimationFrame. Графіка 5/15/30 кадрів/с або вимкнена. Одночасно очікується максимум один запит знімка. Float32 використовується тільки для копії поля на екран, не для фізики.

32², 64², 128² та 256² — це різна площа з незмінною фізичною клітинкою, не роздільна здатність однієї території. Початкова чисельність пропорційна площі: 25, 100, 400, 1600. Концентрація, відновлення, дальність контакту й рух на клітинку однакові. При новому розмірі треба почати новий запуск.

Частота кадрів не керує кроками й не змінює результат за однакового seed та числа кроків. Реальна продуктивність залежить від CPU, числа істот і витрат на копіювання. Браузер може уповільнювати приховані вкладки, а закриття вкладки зупиняє Worker; для автономного прогону є headless.mjs.

Клік показує геном істоти. Лінії — фізичні зв’язки. JSON містить налаштування, поточні метрики й останні 300 вимірювань, не файл відновлення. Покоління може зменшитися, якщо помирає останній представник глибокої лінії. Різноманітність — середньоквадратичне відхилення генів; ген часу нормується на 1000 кроків, щоб зміна одиниць не домінувала в метриці. Додано п’ятий ген, тому метрика не цілком порівнянна зі старими чотиригенними прогонами. JSON версії 3 включає середній геном із тривалістю життя та лічильники причин смерті.

Попередні `core/` і `prototype/` — окремі історичні експерименти. Конектом мухи не підключений. Ця модель не є реалізацією Avida чи Flow-Lenia.
