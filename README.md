# EVO — еволюція простих реплікаторів

Локальна симуляція: істоти рухаються, поглинають ресурс УМП, утворюють фізичні зв’язки, розмножуються з мутаціями та помирають. Мета — спостерігати, що виникає з небагатьох правил, а не програмувати бажаний результат.

**Поточна робоча версія — `basic/`.** Кореневий `index.html`, `core/` та `prototype/` — старі окремі експерименти. Не починай із них.

**Для нового оператора: спочатку прочитай [HANDOFF.md](HANDOFF.md).** Там зафіксовані задум, рішення користувача, стан коду й наступна задача. [Ідея проєкту](docs/IDEA.md) пояснює довгостроковий напрям.

## Запуск

Потрібен Node.js 20 або новіший. Перевірено на Node.js 24.21.0 у Windows. Зовнішні npm-пакети не потрібні; `npm install` не потрібен.

У каталозі завантаженого репозиторію:

```sh
npm start
```

Відкрий [http://127.0.0.1:8100](http://127.0.0.1:8100). Сервер працює лише локально. Зупинити — Ctrl+C. Через `file://` модулі та Worker не запускаються як слід.

Без npm можна виконати `node basic/server.mjs`.

## Перевірки та прогін без графіки

```sh
npm test
npm run sim -- --size=64 --ticks=2000 --seed=1
```

Або напряму:

```sh
node --test basic/core.test.mjs basic/worker.test.mjs
node basic/headless.mjs --size=128 --ticks=2000 --seed=1
```

Під час підготовки передачі 25.09.2026 усі **19 тестів пройшли**. Це перевірки механіки та відтворюваності, не доказ біологічної реалістичності чи нескінченного зростання складності.

## Що вже працює

- П’ять спадкових генів: рух, чутливість до УМП, поглинання, зв’язування, тривалість життя.
- На старті **в кожної істоти ген життя рівно 1000 кроків**, незалежно від інших параметрів. Нащадки успадковують його з можливими мутаціями.
- Пружні фізичні зв’язки, які розриваються при розтягненні або смерті. **Передачі УМП між істотами немає.**
- Поділ, мутації, смерть від виснаження та від досягнення генетичного віку; причини смерті рахуються окремо.
- Детермінований seed, ресурсний баланс, графік популяції, інспектор істоти та експорт спостережень.
- Окремий обчислювальний Worker: графіку можна вимкнути, а розрахунок продовжується.
- Світи 32², 64², 128², 256² зі сталою початковою щільністю істот.

## Що ще НЕ реалізовано

Користувач попросив змінити УМП на більш «ентропійне» середовище й суттєво спростити інтерфейс. Це **наступний етап**, а не властивість поточного коду:

- Зараз поле все ще відновлюється до концентрації 2 зі швидкістю 0.2% за крок, із припливом і відтоком та звичайною дифузією.
- Випадковий локальний обмін за принципом KMP і слабке фонове підживлення обговорені як наступний напрям, але ще не написані.
- Інтерфейс усе ще містить багато панелей і технічних показників; користувач хоче простіше.
- Моделі мозку мухи, конектому, пластичності чи навчання тут немає.

## Орієнтир у файлах

| Шлях | Призначення |
|---|---|
| `basic/core.mjs` | Правила світу, ресурс, геном, реплікатори й зв’язки |
| `basic/runner.mjs` | Прогін кроків і історія вимірювань |
| `basic/worker.mjs` | Незалежний цикл обчислень у Worker |
| `basic/app.mjs`, `basic/index.html`, `basic/style.css` | Поточний браузерний інтерфейс |
| `basic/server.mjs` | Локальний сервер на порту 8100 |
| `basic/headless.mjs` | Прогін без браузера |
| `basic/*.test.mjs` | Тести поточної версії |
| `basic/README.md` | Подробиці реалізованої моделі |
| `HANDOFF.md`, `docs/IDEA.md` | Передача контексту та задум |
| `docs/LEGACY_README.md` | Попередній README для історії |
| `core/`, `prototype/`, `scripts/`, `SPEC-*.md`, `RESULTS-*.md` | Історичні досліди; не актуальні вимоги до basic |

Згенеровані прогони `data/`, `prototype/runs/`, локальні журнали та налаштування інструментів не включені в репозиторій. Старі звіти описують попередні експерименти, а не результати поточної моделі.

Ліцензію на публічне перевикористання коду власник поки не обирав; не вважай цей репозиторій автоматично ліцензованим під MIT або іншу відкриту ліцензію.
